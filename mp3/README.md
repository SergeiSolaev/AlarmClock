# Инструкция по загрузке аудиофайлов 

## Описание папки с аудиофайлами для DF Player Mini

В этой папке хранятся MP3-файлы, предназначенные для загрузки на карту памяти модуля воспроизведения музыки **DF Player Mini**

## Требования к файлам и карте памяти

- **Файловая система**:  
  Карта памяти должна быть отформатирована в **FAT16** или **FAT32**.

- **Имена файлов**:  
  Файлы должны быть названы в формате `0001.mp3`, `0002.mp3` и так далее.  

- **Расположение файлов**:  
  Все аудиофайлы должны быть загружены в папку `01` на карте памяти. Максимальное число файлов в папке `255`.

## Файл сигнала разряда батареи (отключено в v1.0.0)

В папке проекта находится файл:  
`0009_Battery_Discharge.mp3`  

Этот файл используется для воспроизведения сигнала при разрядке батареи.
